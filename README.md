# Control Personal

Aplicación responsive para finanzas personales, alimentación, peso, running y gimnasio.

## Desarrollo local
1. Copia `.env.example` como `.env.local`.
2. Agrega URL y clave pública de Supabase.
3. Ejecuta `npm install`.
4. Ejecuta `npm run dev`.

## Despliegue
Sube este proyecto a GitHub, impórtalo en Vercel y configura las mismas variables de entorno.

No subas `.env.local` a GitHub.
